POSTER HTML/CSS — editable source

Open `poster.html` in Chrome/Chromium. Keep `poster.css` and the `figures/` folder beside it.

- `poster.html` contains editable headings, paragraphs, tables and image references.
- `poster.css` contains the colors, ribbons, layout and A0 print rules.
- `figures/` contains the original research figures.
- Paper size when printing: 841 × 1189 mm (A0, portrait). In Chrome Print select paper A0, margins None, Scale 100%, Background graphics on.
